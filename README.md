# 🎧 SoundLink

음악을 매개로 사용자 간 자연스러운 감정 소통을 유도하는 소셜 플랫폼

**사운드링크**는 **감정을 기록하고 공유할 수 있는 음악 기반 감성 소셜 플랫폼**으로, 같은 감정을 가진 사용자들이 자연스럽게 소통할 수 있는 환경을 제공합니다.

- **음악을 통한 감정 표현**
- **자연스러운 연결**
- **비연애 중심의 감성 커뮤니티**

사운드링크는 기존 SNS와 차별화된 감성 기반 소셜 플랫폼으로, 음악이 단순한 청취 경험을 넘어 사람과 사람을 잇는 연결고리가 될 수 있도록 설계했습니다.
<br>

- 프로젝트 기간 : 2025.02 ~ 진행중
- 배포 주소 : https://www.soundlink.kr
- 시연 영상 : https://www.youtube.com/watch?v=RcabrcJrrAM
